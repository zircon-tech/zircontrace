# Glossary

Terms you'll find across this site, explained in one line.

| Term | What it means |
|---|---|
| **TRACE** | ZirconTech's 5-stage cycle: Target, Read, Architect, Craft, Evolve. |
| **Double Diamond** | A Design Thinking model: first we diverge to fully explore the problem, then we converge on prioritized use cases. It's Target's discovery narrative. |
| **KPI** | Key performance indicator: the concrete metric a use case has to move. |
| **Baseline** | The KPI's value before starting, against which the result is later measured. |
| **Gate** | Each stage's exit criterion: the condition that must be met before moving to the next one. |
| **PoC / MVP** | Proof of concept or minimum viable product: the first version built in Craft to validate the hypothesis. |
| **Traceability artifact** | The Evolve table that compares the objective defined in Target against the result measured in production. |
| **ADR** | Architecture Decision Record: a short document that records an architecture decision and its rationale. |
| **RAG** | Retrieval-Augmented Generation: an AI pattern that combines a language model with a proprietary knowledge base. |
| **FinOps** | Cloud financial management practice, organized into three phases: Inform, Optimize, Operate. |
| **Well-Architected** | AWS's framework with 6 pillars for evaluating the quality of a cloud architecture. |
| **CAF** | AWS Cloud Adoption Framework: a 6-perspective model for evaluating an organization's cloud maturity. |
| **Law 21.719** | Chile's personal data protection law, in effect since December 1, 2026. |
