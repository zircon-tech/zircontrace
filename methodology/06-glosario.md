# Glosario

| Término | Qué significa |
|---|---|
| **TRACE** | El ciclo de 5 etapas: Target, Read, Architect, Craft, Evolve. |
| **Gate** | Criterio de salida de cada etapa: checklist que tiene que cumplirse antes de pasar a la siguiente. No es opcional. |
| **KPI** | Indicador clave de desempeño: la métrica que un caso de uso tiene que mover. |
| **Línea base** | Valor del KPI antes de arrancar, contra el que se mide el delta en Evolve. |
| **PoC / MVP** | Prueba de concepto / producto mínimo viable construido en Craft. |
| **ADR** | Architecture Decision Record: registro corto de una decisión de arquitectura y su justificación, usado cuando la decisión es reversible con costo. |
| **DoD** | Definition of Done: criterio explícito de cuándo una actividad de Craft se considera terminada. |
| **Go/no-go** | Decisión explícita y documentada, con nombre de quién la aprobó, sobre si el PoC pasa a producción. |
| **RAG** | Retrieval-Augmented Generation: patrón de IA que combina un LLM con una base de conocimiento propia (alternativa a fine-tuning). |
| **IaC** | Infrastructure as Code: CDK/Terraform, usado en Craft. |
| **LLMOps / MLOps** | Prácticas operativas para modelos de lenguaje / machine learning en producción: evals, monitoring, drift. |
| **FinOps** | Gestión financiera de la nube en 3 fases: Inform (Architect), Optimize (Craft), Operate (Evolve). |
| **Well-Architected** | Framework de AWS, 6 pilares, usado en Read (revisión) y Architect (checklist de diseño). |
| **CAF** | Cloud Adoption Framework de AWS, 6 perspectivas, usado en Read para el análisis de gaps. |
| **CRISP-DM** | Cross Industry Standard Process for Data Mining: referencia de proceso para Read en proyectos de datos/ML. |
| **Working Backwards / PR-FAQ** | Metodología de Amazon para partir del resultado de negocio (Target), no de la solución técnica. |
| **Double Diamond** | Modelo de Design Thinking del Design Council (UK): divergir para explorar el problema, converger en la solución. Narrativa de discovery de Target. |
| **Ley 21.719** | Ley chilena de protección de datos personales, vigente desde el 1-dic-2026. Sección obligatoria del gate de Read si el cliente opera en Chile. |
| **Catálogo de Paquetes SMB** | Las 8 categorías de servicios de ZirconTech (Seguridad, Costos y FinOps, Arquitectura, Almacenamiento, IA/Agentes/BI, Dev/DevOps, Migración, Integraciones), mapeadas a las etapas de TRACE. |
