**De qué se trata:** radiografiamos el estado actual (datos, arquitectura, riesgos, factibilidad) antes de diseñar nada. Usamos AWS Well-Architected Review y el AWS Cloud Adoption Framework (CAF) como lente, más una verificación explícita de exposición regulatoria.

| | |
|---|---|
| **Te llevás** | Un informe de assessment: gaps por perspectiva del CAF (Negocio, Personas, Gobernanza, Plataforma, Seguridad, Operaciones) con severidad; revisión contra los 6 pilares de Well-Architected; estado de tus datos para el caso de uso elegido; tu exposición bajo la **Ley 21.719** si operás en Chile o procesás datos de personas ahí; y una conclusión clara sobre si es viable seguir a Architect. |
| **Etapa cerrada cuando** | La factibilidad está confirmada: datos, arquitectura y compliance. Cada gap identificado tiene severidad asignada. Recibiste el informe y confirmaste los próximos pasos. |

!!! note "Ley 21.719 (Chile)"
    Vigente desde el 1 de diciembre de 2026. Multas de hasta 20.000 UTM, o 4% de tus ingresos en caso de reincidencia. Durante el primer año de vigencia, solo hay advertencias para pymes.
