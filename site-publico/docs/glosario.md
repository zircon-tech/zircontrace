# Glosario

Términos que vas a encontrar en este sitio, explicados en una línea.

| Término | Qué significa |
|---|---|
| **TRACE** | El arco de 5 etapas de ZirconTech: Target, Read, Architect, Craft, Evolve. |
| **KPI** | Indicador clave de desempeño: la métrica concreta que un caso de uso tiene que mover. |
| **Línea base** | El valor del KPI antes de arrancar, contra el que después se mide el resultado. |
| **Gate** | El criterio de salida de cada etapa: la condición que tiene que cumplirse antes de pasar a la siguiente. |
| **PoC / MVP** | Prueba de concepto o producto mínimo viable: la primera versión que se construye en Craft para validar la hipótesis. |
| **Artefacto de trazabilidad** | La tabla de Evolve que compara el objetivo definido en Target contra el resultado medido en producción. |
| **ADR** | Architecture Decision Record: documento corto que registra una decisión de arquitectura y su justificación. |
| **RAG** | Retrieval-Augmented Generation: patrón de IA que combina un modelo de lenguaje con una base de conocimiento propia. |
| **FinOps** | Práctica de gestión financiera de la nube, organizada en tres fases: Inform, Optimize, Operate. |
| **Well-Architected** | Framework de AWS con 6 pilares para evaluar la calidad de una arquitectura en la nube. |
| **CAF** | Cloud Adoption Framework de AWS: modelo de 6 perspectivas para evaluar la madurez de una organización en la nube. |
| **Ley 21.719** | Ley chilena de protección de datos personales, vigente desde el 1 de diciembre de 2026. |
